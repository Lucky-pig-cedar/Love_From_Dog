# Love From Dog

MIMOMO & JIGOGO 的聊天空间。默认与“汤”的 AI 分身聊天，“牛顿的火焰激光剑”的 AI 分身暂未开放。头像来自本人指定的两张图片，聊天右侧的用户头像使用小鸟。

这里仅包含静态网页和公开的接口地址。密钥、人格资料、聊天原文、语音样本、检索索引及聊天数据库均不在这个公开仓库。

## GitHub Pages

将本目录中的文件上传到 `Lucky-pig-cedar/Love_From_Dog` 的 `main` 分支根目录。
打开仓库 **Settings → Pages**，选择 **Deploy from a branch → main → /(root) → Save**。
部署地址为 `https://lucky-pig-cedar.github.io/Love_From_Dog/`。

实际聊天请使用已有的完整专属邀请链接，其中包含进入权限。页面从 endpoint.json 读取私有云后台的接口地址；该文件不包含密钥。不要把完整邀请链接或密钥提交到公开仓库。

GitHub Pages 提供界面；Cloudflare 私有后台提供身份、人格参考、RAG 和设备隔离的聊天记录，DeepSeek 提供文字回复，通义官方声音复刻服务提供本人音色的语音。网站聊天和生成新语音无需本地电脑在线。模型调用按提供方用量计费，云平台额度以账号实际配置为准。

原始语音样本只通过私有流程交给官方音色服务，不通过网页分发。语音播放需要相同邀请权限和原浏览器设备权限；临时音频链接不发给前端，过期后可按需重新合成。仅开放“汤”，女朋友分身仍等待后续明确同意。

聊天记录按浏览器设备分别保存到私有云数据库。清理浏览器存储或换设备后不会自动恢复原设备的历史。
